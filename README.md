# Transit Delay Prediction System

A machine learning system that analyzes historical and real-time transit data to predict bus delays and improve arrival time accuracy.

## Overview
This project focuses on improving public transit reliability by comparing scheduled and actual arrival times using GTFS data. Machine learning models are used to predict delays and provide more accurate estimates.

## Features
- Processing of GTFS transit data (historical and real-time)
- Data cleaning and preprocessing for machine learning
- Training and evaluation of prediction models
- Improved arrival time estimation
- Integration of model outputs with user-facing explanations

## Tech Stack
- Python
- pandas, NumPy
- scikit-learn
- GTFS data
- Machine Learning models

## Methodology
1. Collect and parse GTFS data
2. Clean and preprocess datasets
3. Train machine learning models for delay prediction
4. Evaluate models using performance metrics
5. Generate improved delay estimates
