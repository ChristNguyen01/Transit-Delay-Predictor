# AI-Powered Transit Delay Prediction Assistant

This project analyzes public transit GTFS data to predict bus delays using machine learning models and explain predictions using large language models.

## Overview

Transit systems generate large volumes of schedule and real-time location data. This project processes historical and live GTFS data to estimate delays and provide user-friendly explanations of expected arrival times.

## Features

* Processing of historical and real-time GTFS transit data
* Machine learning model for delay prediction
* ETA estimation using live arrival data
* Natural language explanations generated by an LLM

## Tech Stack

* Python
* pandas
* NumPy
* scikit-learn
* GTFS transit data
* LLM integration

## Pipeline

GTFS Data → Data Processing → ML Model → Delay Prediction → LLM Explanation

## Example Use Case

Input:
Bus route schedule and real-time arrival data

Output:
Predicted delay with explanation such as:
"The bus is expected to arrive 6 minutes late due to heavy congestion along the route."
